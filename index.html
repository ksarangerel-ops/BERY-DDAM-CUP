    CHECK-IN
    1. CS2 тоглоомоо хамгийн сүүлийн хувилбарт шинэчилсэн байх.
    2. Steam болон CS2 аккаунтдаа асуудалгүй нэвтэрсэн байх.
    3. Шаардлагатай тохиргоо, файлуудаа бэлэн байлгах.

    5. Шаардлагатай бол зохион байгуулагчийн өгсөн сервер, lobby-г ашиглах.

    Сервер, map эсвэл match-тэй холбоотой асуудлыг зөвхөн зохион байгуулагч / шүүгч шийдвэрлэнэ.

    07

    Оноо ба Seed эрэмбэ

    STANDINGS / TIEBREAK
    1 POINTMatch Win
    0 POINTMatch Loss

    Group Stage-ийн байрлалыг дараах дарааллаар тогтооно:

    1. Нийт Match Win — олон хожилтой баг өндөр байр эзэлнэ.
    2. Head-to-Head — яг 2 баг тэнцсэн тохиолдолд шууд тоглолтын үр дүн.
    3. Round Difference — 3 ба түүнээс олон баг тэнцвэл нийт Round Win − Round Loss.
    4. Нийт Round Win — дээрх үзүүлэлтүүд тэнцсэн тохиолдолд.
    5. BO1 tie-breaker — шаардлагатай бол зохион байгуулагчийн шийдвэрээр.

    Цаг баримтлах ба техникийн асуудал

    SERVER / TECH PAUSE
    1. Тоглолт эхлэхэд баг бүр 5 тоглогчтой бүрэн бүрэлдэхүүнтэй байна.
    2. Зөв сервер / lobby-д орсон байх.
    3. Зохион байгуулагчийн зааврыг дагаж мөрдөнө.
    4. Интернет, компьютер, CS2 crash, FPS, Steam-ийн хувийн асуудлаар match автоматаар restart хийхгүй.
    5. Pause, үргэлжлүүлэх эсвэл rematch хийх эсэхийг зохион байгуулагч шийднэ.
    6. Серверийн нийтлэг асуудал, server crash, зохион байгуулагчийн техникийн алдаанд rematch хийх эсэхийг зохион байгуулагч шийдвэрлэнэ.
